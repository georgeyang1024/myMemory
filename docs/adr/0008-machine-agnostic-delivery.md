# ADR-0008 · 交付边界：只交付机器无关源码

**状态**：已采纳 · 2026-09-02

## 背景

需求为"局域网访问、无需授权"。实测当前开发环境的网络拓扑：

```
CODESPACES=true            ← GitHub Codespace，非本地 Docker
eth0  172.18.0.2/16        ← Codespace 内网地址
utun0 198.18.0.1/30        ← 点对点隧道（127.0.0.1:7890 + :9090，Clash 式代理）
```

- **出站**：`192.168.4.234:7081` 可达、`gitlab.lovense.cn:16666` 可达
- **入站**：不可能。无任何网卡持有局域网地址；utun0 是 `/30` 点对点客户端隧道。
  Codespace 唯一对外暴露方式是 GitHub 端口转发（`*.app.github.dev`），
  那是公网域名 + 强制 GitHub 鉴权，与"局域网 + 免授权"两条都不满足

这是拓扑问题而非配置问题，没有绕过办法。

## 决策

本次只交付源码。服务实现与部署位置完全解耦：

- 代码中不硬编码任何 IP
- 绑定地址、端口、知识库根目录全部通过环境变量注入
- 开发期在 Codespace 用 `127.0.0.1` 完成功能验证
- 实际运行由使用方自行执行

部署机器选型、端口分配、知识库同步策略、服务器权限**均不在本次范围内**。

## 后果

- 代码可在任意机器零改动运行（Linux 服务器、Windows 本机均可）
- 交付物包含双平台启动脚本 → [ADR-0011](0011-pinned-deps-both-platforms.md)
- 若后续部署到 `192.168.4.234` 一类常驻服务器，知识库同步的自然解法是
  服务器 `git clone` + cron `git pull`——pull 完成后 60 s 内
  [ADR-0007](0007-in-memory-index-with-polling.md) 的 mtime 轮询会自动重建索引，
  两者天然衔接。但该路径本次不实施
