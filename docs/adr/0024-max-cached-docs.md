# ADR-0024 · 常驻内存的全文最多 max_cached_docs 篇（LRU）

**状态**：已采纳并实施 · 2026-09-24

索引的正文随库线性膨胀。决定用 `config.json` 的 `max_cached_docs`（默认 1000，`0` 不限）限制
**常驻内存的全文篇数**，超出按 LRU 丢弃；**所有文档照常进索引、照常可检索**。
为此全文从文件条目中移出，放进一个共享的 LRU 缓存；块也不再存正文副本，片段按偏移从全文切出。
`get-document` 与检索片段先查缓存，没有就读盘并放进缓存；掉盘且不在缓存里的，全文读不到、片段为空
（`snippet_available: false`）。缓存着的全文随 index.cache 持久化，缓存格式版本升为 3。

曾先误实现为"限制索引文档总数、按 LRU 淘汰出索引"（配置名 max_docs），会让被淘汰的文档搜不到，
与意图不符，已撤回。另注：实测全文与块正文只占进程内存的一小部分（约 60 MB / 460 MB），
大头是分词结果与 BM25 统计；若要大幅降内存，下一步应是"分词结果不常驻内存"。
