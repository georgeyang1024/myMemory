# ADR-0021 · 只在当前系统运行，虚拟环境统一为 .venv

**状态**：已采纳并实施 · 2026-09-24
**部分取代**：[ADR-0011](0011-pinned-deps-both-platforms.md) 的双平台部分

按平台分目录的虚拟环境（`.venv-windows` / `.venv-linux`）、拒绝清空另一平台环境、旧目录迁移提示，
都是为"同一目录被两个系统同时使用"设计的。实际只在 Windows 上运行，这套机制反而造成过事故：
两个平台共用 `logs/` 时 PID 文件被另一边覆盖并删除，导致 `run.py --restart` 找不到旧进程。
决定只在当前系统运行，保留虚拟环境（依赖仍锁精确版本，ADR-0011 的这一半不变），统一为 `.venv`，
删除跨平台机制与对应测试；开发与测试也在 Windows 的 `.venv` 中执行。
